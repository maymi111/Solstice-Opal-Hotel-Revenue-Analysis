# Solstice Opal Hotel Revenue Analysis

This project was completed as part of the DataCamp Data Analyst Certification Practical Exam.

## Project Overview

The objective was to analyse ancillary revenue patterns and identify high-value guest segments that contribute the most revenue.


## Business Problem

Solstice Opal Hotel wants to understand:

- Which guest segments generate the highest ancillary revenue?
- What characteristics are associated with high-value guests?
- How can the hotel increase ancillary revenue?

## Dataset

This project uses a hypothetical hotel dataset provided by DataCamp for certification assessment purposes.

## Tools & Skills

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

Skills:
- Data cleaning
- Data validation
- Data merging
- Exploratory Data Analysis
- Customer segmentation


## Key Findings

- The top 10% highest-spending guests contributed approximately 35.31% of total ancillary revenue.
- Platinum members showed the highest average spending.
- Business travellers generated higher ancillary spending than leisure travellers.
- Corporate booking guests spent 12.2% more than website booking guests.


## Recommendations

- Target Platinum business travellers with personalised upselling campaigns.
- Develop additional packages through corporate channels.
- Create VIP retention strategies for high-value guests.
